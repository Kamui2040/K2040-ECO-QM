# ECO Quick Menu Additions — Single Patches

The Single Patches release track provides the current K2040 ECO Quick Menu compatibility patches as separate archives so you can install only the weapons you use.

## Current release

The current Nexus release is **1.0** and lists 12 optional patch downloads:

- AER15 Modern Laser Assault Rifle
- MEC-R7 variant
- H&K 45C Mk24
- X12 Plasmacaster
- AQUILA Laser Rifle
- DKS-501 Redux
- ACR-W17
- DKS-501 Unofficial Update Vanilla compatibility
- DKS-501 Sniper Rifle
- Alex's .357 Cattleman Revolver
- Modern Warfare 2019 FAL
- HK USP

All current K2040 patches are ESL-flagged ESP plugins.

## Requirements

Install ECO Redux and its requirements first. Each patch also requires its matching weapon mod and any dependencies required by that weapon or compatibility variant.

The Nexus page contains the authoritative dependency links for the current patches.

## Installation

Install the requirements, then install only the patch archives for the weapons and variants present in your load order.

## Legacy files

The older Nexus project `K2040's Eco Quick Menu Additions` (mod 104590) was replaced by this current release line. Archives from that predecessor are historical material and must not be mixed into the current 12-patch release. Historical files can be preserved separately once their exact identity and status have been verified.

# ECO Quick Menu Additions — AiO installer

This directory identifies the **AiO installer** release track for K2040's released Fallout 4 ECO Quick Menu compatibility patches.

## Official sources

- GitHub release home: <https://github.com/Kamui2040/K2040-ECO-QM/releases>
- Nexus Mods: <https://www.nexusmods.com/fallout4/mods/105461>
- K2040 project page: <https://kamui2040.github.io/K2040-Gaming-Mods/projects/project.html?project=eco-quick-menu-additions>

The downloadable files themselves belong in GitHub Releases, not in this directory. Release titles, tags, notes, filenames, and checksums must clearly identify the AiO track and match the verified published release.

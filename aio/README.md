# ECO Quick Menu Additions — AiO installer

The AiO is the recommended single-package installation for the current K2040 ECO Quick Menu Additions release line.

## Current version

**1.0.1.11**

The FOMOD uses plugin detection to present the compatibility patches that match the supported weapons in your load order.

## Included support

- HK USP
- DKS-501 Sniper Rifle
- Alex's .357 Cattleman Revolver
- Modern Warfare 2019 FAL
- ACR-W17
- DKS-501 Redux
- AQUILA Laser Rifle
- X12 Plasmacaster
- H&K 45C Mk24
- AER15 Modern Laser Assault Rifle
- MEC-R7 variant for AER15

## Requirements

ECO Redux and its requirements are required. Install the weapon mods and any dependencies needed by the patches you want to use before installing the AiO.

The Nexus page contains the authoritative links for the current weapon and optional compatibility requirements.

## Installation

1. Install ECO Redux and its requirements.
2. Install the supported weapon mods you use and their requirements.
3. Install the AiO FOMOD.
4. Select the detected patches that match your load order.

All included K2040 patches are ESL-flagged ESP plugins.

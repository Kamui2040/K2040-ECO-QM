# K2040 ECO Quick Menu Releases

This public repository is the official K2040 GitHub home for two released Fallout 4 ECO Quick Menu projects:

- **ECO Quick Menu Additions — AiO installer**
- **ECO Quick Menu Additions — Single Patches**

The K2040 Gaming Mods website remains the presentation and project-information layer. This repository is the GitHub release home for the downloadable ECO files, while Nexus Mods remains an official distribution source.

## Release tracks

### AiO installer

The AiO release track provides the complete released compatibility-patch collection through one installer.

- Release area: [`aio/`](aio/)
- Nexus Mods: <https://www.nexusmods.com/fallout4/mods/105461>

### Single Patches

The Single Patches release track provides the individual optional compatibility patches separately.

- Release area: [`single-patches/`](single-patches/)
- Nexus Mods: <https://www.nexusmods.com/fallout4/mods/105464>

## Project page

The combined project page is available on the K2040 Gaming Mods site:

<https://kamui2040.github.io/K2040-Gaming-Mods/projects/project.html?project=eco-quick-menu-additions>

## Downloads

Published GitHub files belong in this repository's **Releases** section. Each release must clearly identify whether it belongs to the AiO or Single Patches track and must match the verified release file, version, checksum, notes, licence information, and attribution for that release.

Until a matching GitHub release is actually published here, use the corresponding Nexus Mods page above for the released files. Repository documentation is not itself a release artifact.

## Scope

This repository is only for the two released ECO Quick Menu tracks listed above. It does not host unrelated projects, private development work, or the separate in-development Prisma ECO Quick Menu project.

Release-specific licence and attribution information will be preserved with the applicable release. No unrelated rights or permissions are implied by this repository.
